🎯 Overview

This tutorial walks through the complete process of using mlx-serve with the Qwen3.8-27B-AEON-ULTIMATE-UNCENSORED-oQ8e-mtp model to generate a Flappy Bird game via the FlappyBench benchmark prompt. We'll cover everything from downloading the model weights to deploying a local OpenAI-compatible API server and generating production-ready code.

What you'll build: A complete, playable Flappy Bird game in a single HTML file with Canvas rendering, smooth physics, parallax backgrounds, score tracking, collision detection, and persistent high scores.

🎮 Step 4: Generate Flappy Bird (FlappyBench)

1

The FlappyBench Prompt

This is the exact prompt from the FlappyBench benchmark:

Prompt:
"Create a complete single HTML file for a cute Flappy Bird style game using Canvas. Smooth gravity, flapping animation, parallax background, score, pipe obstacles, game over screen"
2

Send generation request

Critical: Use max_tokens: 32768 — the complete game needs ~9000 tokens. Lower limits will truncate the output.

$ curl -X POST http://localhost:11234/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "swdjojo/Qwen3.8-27B-AEON-ULTIMATE-UNCENSORED-oQ8e-mtp", "messages": [ {"role": "user", "content": "Create a complete single HTML file for a cute Flappy Bird style game using Canvas. Smooth gravity, flapping animation, parallax background, score, pipe obstacles, game over screen"} ], "max_tokens": 32768, "temperature": 0.3, "stream": true }'

3

Save the output

The streaming response will output SSE (Server-Sent Events). Extract the content and save:

$ # Save to file (extract content from SSE stream) curl -X POST ... > flappy_response.json # Or use the Python script below to extract and save

Python helper to extract SSE stream

import json
import sys

def extract_sse_content(stream_file, output_file):
    content = ""
    with open(stream_file) as f:
        for line in f:
            if line.startswith("data: "):
                data = line[6:].strip()
                if data == "[DONE]":
                    break
                try:
                    chunk = json.loads(data)
                    delta = chunk.get("choices", [{}])[0].get("delta", {})
                    if "content" in delta:
                        content += delta["content"]
                except:
                    pass
    with open(output_file, "w") as f:
        f.write(content)
    print(f"Extracted {len(content)} characters to {output_file}")

extract_sse_content("flappy_response.json", "index.html")

🔧 Troubleshooting & Tips

Common Issues

IssueSolution
Output truncated (finish_reason: "length") Increase max_tokens to 32768. The game needs ~9000 tokens.
Model not found (404) Use exact model ID: swdjojo/Qwen3.8-27B-AEON-ULTIMATE-UNCENSORED-oQ8e-mtp
Out of memory Close other apps; model needs ~28 GB RAM. Use --kv-quant 4 to reduce memory.
Port 11234 in use Run pkill -f mlx-serve then restart
Slow generation Enable MTP: add "enable_mtp": true to request

Useful mlx-serve Flags

# Reduce memory with KV quantization
mlx-serve serve --model-dir ~/.lmstudio/models --port 11234 --kv-quant 4

# Disable PLD (Prompt Lookup Decoding)
mlx-serve serve --model-dir ~/.lmstudio/models --port 11234 --no-pld

# Force MTP on for all models
mlx-serve serve --model-dir ~/.lmstudio/models --port 11234 --mtp

# Custom context size
mlx-serve serve --model-dir ~/.lmstudio/models --port 11234 --ctx-size 32768
